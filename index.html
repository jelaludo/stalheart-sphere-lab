STÅLHEART / DEVLOG 001

Putting an organic quad grid on a sphere

This prototype asks a deliberately awkward geometry question: can Stålberg-style, relaxed quad patches live inside a mostly-hexagonal spherical world while all unavoidable defects are localized into two readable polar crowns?

01 — Two meshes, not one

The useful abstraction is a three-layer stack. The macro topology owns cell identity and neighbor invariants. A canonical patch boundary owns every shared corner, edge sample, and subdivision midpoint. The micro mesh runs the organic Stålberg process inside each macro-cell.

Trying to make one mesh serve all three jobs coupled visual relaxation to gameplay topology. Separating them lets the micro-grid move freely while the macro graph remains exact and inspectable.

macro graph → canonical boundary contract → relaxed quad patches

02 — The spherical defect budget

For a trivalent polygon tiling of a sphere, Σ(6 − sides) = 12. Twelve pentagons are not an implementation accident; they are the curvature budget. STÅLHEART places six degree-five cells in the first northern collar and six in the southern collar. Every other macro-cell has degree six.

Each pole retains a tiny, degree-six epsilon cap. Collapsing that cap to a literal point looks tempting, but it either creates zero-area faces, changes the crown cells to four-neighbor regions, or violates the ordinary trivalent tiling. The finite cap is the smallest honest compromise: visually unified at game distance, topologically non-degenerate under inspection.

03 — The Stålberg process, for real

Every macro-cell receives a generalized patch. Six-sided cells use six sectors; crown pentagons use five. Within a patch we generate concentric polygon rings, connect them as triangle bands, randomly dissolve non-conflicting adjacent triangle pairs, subdivide surviving triangles into three quads, subdivide each dissolved quad into four quads, then perform tangent-space Laplacian relaxation.

The random choice is seeded. Border points never participate in relaxation. Interior displacement is projected into the local tangent plane and the result is normalized back to the sphere.

triangle bands
  → maximal seeded triangle pairing
  → triangles × 3 quads / dissolved quads × 4 quads
  → fixed-boundary Laplacian relaxation
  → spherical projection

04 — Seams are a data-ownership problem

Generating adjacent patches independently—even with identical formulas—is not a robust seam strategy. Each undirected macro-edge therefore has one canonical ordered sample sequence. The neighboring patch consumes the same objects in reverse order. Corners are keyed globally, as are the midpoints introduced when the triangle/quad network is subdivided.

This is stronger than epsilon-based coordinate welding: object identity itself expresses ownership. The test suite rebuilds the final quad complex from those identities and verifies that every micro-edge has exactly two incident quads.

05 — Failures that changed the design

Organic icosphere
Topologically sound, but its twelve pentagons remained geographically scattered. Labeling the nearest six “north” did not create crowns.
Visual pole convergence
Pulling unrelated dual vertices toward a pole produced convincing statistics and broken visible joints. Rendering validity is not topology validity.
Deleting the pole cell
The crown looked cleaner, but every pentagon became a four-neighbor adapter. Euler still passed in the restricted version; the requested degree invariant did not.
Angle-sorted dissolved quads
Projection-based sorting failed on curved polar patches and generated crossing edges. The fix was purely topological: remove the shared triangle edge and walk the four surviving boundary edges.
“Both endpoints are border vertices”
At low ring counts, an interior diagonal can satisfy that test. Explicit cyclic boundary-edge membership is required.

06 — What is actually validated

The automated matrix varies macro bands, micro rings, and seeds. It checks macro and micro Euler characteristic, two-face/two-quad edge incidence, exactly twelve degree-five pentagons, six per crown, two non-degenerate degree-six caps, deterministic generation, finite coordinates, non-zero quad edges, subdivision accounting, and canonical shared-sample counts.

The green badge is therefore a statement about both visible quad connectivity and the gameplay-scale topology—not merely the source triangulation.

08 — Deliberate compromises

This is a geometry laboratory, not the final game graph. Macro density is intentionally conservative because crown-preserving refinement needs transition-cap templates rather than blind midpoint subdivision. The micro-grid provides the high-frequency playable/visual structure. The pole cap remains visible in debug mode because hiding it would hide the exact place where topology and art direction negotiate.
